ONE PIECE-INSPIRED BIRTHDAY INVITATION

FILES
- index.html
- style.css
- script.js
- assets/ (create this folder for your photos and optional music)

PERSONALIZE
1. Open script.js.
2. Edit the INVITATION object at the top:
   celebrantName, occasion, dateText, timeText, eventDateTime,
   churchName, churchAddress, churchSchedule, churchMaps,
   receptionName, receptionAddress, receptionSchedule,
   receptionMaps, and rsvpLink.
3. Replace the bracketed dress-code, gift, and timeline text in index.html.
4. Add assets/celebrant.jpg, assets/photo-1.jpg, assets/photo-2.jpg,
   assets/photo-3.jpg, and optionally assets/music.mp3.
5. For Google Maps, open the correct place in Google Maps, choose Share,
   copy the link, and paste it into the matching *Maps value in script.js.
6. For RSVP, create a Google Form and paste its responder link into rsvpLink.

COUNTDOWN DATE
Use local date/time in this format: YYYY-MM-DDTHH:MM:SS
Example: 2027-05-16T17:30:00
Use the event's local time.

ACODE
Keep all three main files in the same project folder. Preview index.html.

GITHUB PAGES
Create a GitHub repository, upload index.html, style.css, script.js and
the assets folder. In repository Settings > Pages, select Deploy from a
branch, choose main and /(root), then Save. Wait for the published URL.
